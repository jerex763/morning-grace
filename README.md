# 晨光 Morning Grace

> 每天的例行播报——天气、中文要闻、读经，全程自动，无需对话。

一款面向华人长辈的 Android 定时播报助手。闹钟触发后自动连续播报天气、
三条中文要闻和当天读经；首页与通知栏都可一键停止。

---

## 功能

| 功能 | 说明 |
|------|------|
| ⏰ 定时闹钟 | 每日定时触发，精确闹钟，重启后自动恢复 |
| 🌤 天气播报 | 中国气象局天气实况；定位失败时明确播报北京天气 |
| 📖 圣经读经 | 默认且只播中文和合本；支持每日内容预览与进度调整 |
| 🎧 真人录音 | 导入按章 MP3/ZIP 后优先播放真人录音，缺章自动回退中文 TTS |
| 📰 中文要闻 | 中新网公开 RSS，每日三条；默认官方概述，可选完整正文 |
| 📍 GPS 定位 | 已授权时自动刷新当前位置，无需手动更新 |
| 👴 长辈模式 | 大字体、大按钮、简单首页、通知栏一键停止 |

## 读经计划

- **麦大卫一年读经** — 正式 365 天表，每天4段，旧约+新约交叉阅读
- **顺序读经** — 每天1章，创世记 → 启示录
- **每天三章** — 从用户指定的书卷和章节开始，每天连续阅读3章

三种计划均可查看当天书卷和章节，并可手动选择当前计划进度。

## 真人录音

设置页可一次选择一个或多个 WordProject 按卷 ZIP。App 会安全解压、按
`书卷/章节` 建立本地索引，并在晨间播报时优先播放对应录音。

- 音频保存在 App 专属存储，不增加 APK 大小。
- 找不到录音或播放失败时自动使用中文系统语音；系统 TTS 不可用时，
  已导入的真人录音仍会继续播放。
- 音频文件受原提供方版权约束，不提交 GitHub，也不随 APK 分发。
- App 不直接链接 WordProject 音频服务器；详细导入方法见
  [docs/AUDIO_IMPORT.md](docs/AUDIO_IMPORT.md)。

## 数据来源

| 数据 | 来源 | 费用 |
|------|------|------|
| 天气 | 中国气象局公开接口 | 免费，无需 API key；默认北京 |
| 新闻 | 中国新闻网公开 RSS 与文章页 | 免费 |
| 圣经 | 和合本（公版）+ KJV（公版） | 免费 |
| 可选录音 | 用户自行合法下载并导入 | 仅本地保存 |

## 技术栈

- **语言**：Kotlin
- **架构**：多模块，Hilt 依赖注入，Coroutines
- **数据库**：Room（圣经 62,000 节经文）
- **网络**：OkHttp
- **UI**：Material Design 3

## 模块结构

```
morning-grace/
├── app/          # UI、设置页、Hilt 入口
├── core/         # 共享数据模型与接口
├── alarm/        # 闹钟调度、BroadcastReceiver、前台 Service
├── orchestrator/ # 播报流程状态机（核心业务逻辑）
├── bible/        # 圣经文本数据库与读经计划
└── tts/          # 中文 TTS
```

```bash
./gradlew assembleDebug   # 构建 APK

```
