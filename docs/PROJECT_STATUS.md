## 当前未完成：更自然的圣经人声

当前 Android TTS 已限制为默认中文，但声音仍可能偏机械。

已经确认的方向：

- 用户已下载 WordProject 的《创世记》音频包 `01_GEN.zip`。
- 该包包含按章划分的真人 MP3；《创世记》解压后约 85 MB。
- 全本音频预计约 1.5–2.5 GB，不适合直接打进 APK。
- Morning Grace 为个人自用时，可把合法下载的录音保存在手机本地。
- 录音文件不能提交到公开 GitHub，也不应放进公开发布的 APK。

推荐实现：

1. 增加“导入圣经音频包”入口。
2. 将 MP3 复制到 App 专属存储，按书卷和章节建立索引。
3. 播报当天经文时优先播放匹配的真人录音。
4. 缺少录音的章节自动回退到现有中文 TTS。
5. 先只接入《创世记》验证命名映射、连续播放、暂停和闹钟流程。
6. 验证通过后再逐卷导入，避免 APK 和 GitHub 仓库膨胀。

另外调查到 Open Bible 有完整的中文神经 AI 有声圣经，但其译本是 OTB，
不是 Morning Grace 当前使用的和合本，音频再利用授权也不明确，因此不直接提取。
