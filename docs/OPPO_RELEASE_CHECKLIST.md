# OPPO A1x 5G 交付验收

目标设备：OPPO A1x 5G（PHJ110）、Android 13。每个正式版本交给老人前，都要在
这台真机完成下面测试。模拟器不能替代 ColorOS 后台管理测试。

## 首次安装

1. 卸载旧测试版后安装正式签名 APK。
2. 确认首次进入依次申请通知和位置权限，没有长时间无说明的停顿。
3. 确认首次默认读经计划为“每天三章”，首页能看到当天三章。
4. 允许通知；拒绝通知时，App 不应允许误开启闹钟。
5. 在系统设置允许晨光自启动、后台活动和忽略电池优化，并确认媒体音量不为零。

## 播放与离线

1. 导入 ZIP 后确认显示 `真人录音：1189 / 1189 章`。
2. 有网立即测试：天气 → 真人读经 → 三条新闻，通知栏“停止播放”立即有效。
3. 飞行模式立即测试：只提示一次“当前没有网络”，随后直接播放真人读经。
4. 锁屏、切换 App、熄屏 20 分钟，音频应持续且章节之间不中断。
5. 播放中拔耳机、接电话或让其他 App 抢占音频，晨光应暂停或降低音量，不叠音。

## 闹钟可靠性

分别把闹钟设置到 5 分钟后，并完成：

1. 普通锁屏等待。
2. 手机重启后不再打开晨光，锁屏等待。
3. 手动改变系统时间和时区后，确认闹钟按新时间重新安排。
4. 连续三个夜晚保持锁屏，记录是否准时启动和通知栏停止按钮是否可用。

## 显示与升级

1. 把系统字体、显示大小调到老人实际使用的最大档，首页和设置文字不能被截断。
2. 用同一正式签名安装下一版本，必须可以直接覆盖升级。
3. 覆盖升级后确认闹钟设置、读经进度和 1189 章录音仍然存在。
