# Morning Grace 老人友好版

分支：`agent/senior-friendly-ui`

## 产品目标

为老人和不熟悉智能手机的用户提供一版字大、步骤少、按钮明确的 Morning Grace。
首页应当不需要学习即可完成最常用的两件事：查看今天读什么、开始或停止晨间播报。

## 已确认需求

- 全局使用更大的中文字体和更高对比度。
- 减少首页信息密度，复杂设置收进设置区域。
- 首页提供一个大面积“开始今天的播报”按钮；播放时同一位置变为“停止播放”。
- 通知栏提供醒目的“停止播放”操作。
- 播报流程不再通过 AI 语音询问是否继续，内容自动连续播放。
- 移除财经模块和财经播报。
- 新闻改为面向中国用户的综合热点新闻，每次选取前三条。
- 新闻默认播报标题与 RSS 官方概述；设置中可选择播报可获取的完整正文。
- 删除 AI 语音对话、Gemini API Key 输入和麦克风权限。
- 真人圣经录音与系统语音之间避免明显的音量跳变。
- 保留三种读经计划、计划日选择、真人圣经录音和中文 TTS 回退。

## 第一版 UI 原型范围

- 大标题、大时间、大按钮、大号今日读经文字。
- 首页只展示天气、今日读经和今日三条新闻。
- 闹钟、读经计划、真人音频与位置放入“设置”。
- 播放按钮必须有明确的开始/停止状态，不使用只有图标而没有文字的关键操作。

## 新闻实现约束

- 新闻源需要稳定、可合法读取，并能提供正文或足够完整的摘要。
- App 不复制或永久存储第三方新闻全文；只在播报时读取并做短期缓存。
- “类似今日头条”指内容取向和前三条热点体验，不默认使用或冒充今日头条官方接口。

## 验收标准

- 老人不进入设置即可开始和停止当天播报。
- 戴老花镜的用户在常见 6 英寸手机上能清楚辨认首页关键文字。
- 播报启动后无需说话或触摸即可依次完成天气、当天读经、三条新闻。
- 锁屏或切到其他 App 后，通知栏仍可一键停止播放。
- 真人经文进入系统语音段落时没有突兀的音量变化。
- 没有网络时不等待天气或新闻请求，提示一次后直接播放本地真人录音。
- OPPO 真机在重启、锁屏和系统时间/时区改变后仍能按新时间触发。
